Ensemble Radar

Five signals, one implied value, every pre-token protocol on the watchlist.

How a row is scored

Each protocol's implied value is its TVL times four signal multipliers, all read off the sealed snapshot alone. No protocol name is ever special-cased.

  1. Value anchor · 25%TVL × the category's own market multiple — the median mcap/TVL of the protocols with a token in the same category. Categories with fewer than 3 live peers use the global median.
  2. Momentum · 25%Seven-day TVL change, clamped to −60%…+150%, as a multiplier of 1 + growth × 0.6.
  3. Tenure · 20%How long it has run with no token: age since first listed, saturating at 3 years.
  4. Reach · 10%Chains it runs on, capped at 8: +4% per chain.
  5. Scale · 20%Log TVL, normalised across the board itself. It shapes the conviction score, not the value.

implied = TVL × category multiple × momentum × tenure × reach  ·  ensemble = 0.20·scale + 0.25·multiple + 0.25·momentum + 0.20·tenure + 0.10·reach

“Records no token” means the snapshot's record names none — a protocol on this board may still have a token its DefiLlama record does not carry. An implied value is this radar's own claim about what a token would be worth if the protocol's record stayed as it is; it does not predict whether or when a token is issued. Above-floor protocols the house rule leaves off the watchlist stay off this board for the same reason: wrapped, staked or bridged products, versioned pools and exchanges are not standalone launches.

Source: DefiLlama protocols endpoint, fetched once and sealed in the snapshot; the board is recomputed from that snapshot on every run, with no network. Board rows carry a seven-step farm plan with a cost and a time for every step.
